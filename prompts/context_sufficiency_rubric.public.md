# study04 規定度ルブリック（採点の物差し・校正済み）

STEP3 で 02_label.tsv を採点する際の判定基準。DESIGN.md の定義の操作版。
taichi（キャラ設計者）本人による診断的アノテーション。第三者/blind/客観測定とは主張しない。

## 規定度が答える問い
**「この content key（gold の内容要素）の"実質"は、提示文脈だけから観察・推定できるか？」**

- 問うのは「文脈がこの応答を**唯一に強制するか**」ではない（それを基準にすると全部 0〜1 に潰れ、尺度が死ぬ＝「文脈不足」の自作自演バイアス）。
- 測るのは「**実質を支える手がかりが入力文脈にあるか**」。複数の妥当な応答がありえても、各々が十分手がかりづけられていれば高規定度になりうる。
- 「生成が再現できたか」は別物（再現 ○△× の列）。ここは **文脈 対 key** だけを見る。

## 4段階（判定ラダー：上から YES/NO で降りる）
1. 要素の実質が**文面に直接出ている**？ → **3 明示**
2. （NO）**一般常識・状況推論だけ**で文脈から導ける（前提が全部文脈内）？ → **2 推定可能**
3. （NO）**外部文脈**（キャラ気質・来歴・関係性・前シーン・非言語/画面外）を持ち込めば支えられる？ → **1 外部文脈依存**
4. （NO・手がかり皆無／gold を見て初めて分かる／外的兆候ゼロの内的状態）→ **0 不可視**

## ガードレール
- **キャラ知識での補完は 2 でなく 1。** 「この人物はこういう性格だから」という補完は外部知識。2 はキャラを知らない一般読者でも状況から導ける場合のみ。
- **gold を見た後の後付け正当化をしない。** アンカーは STEP2 メモ（文脈だけで書いた読み）。メモに既に手がかりがある→2〜3 の証拠／key が gold を見て初めて通る→1〜0 の証拠。
- **困っても機械的に低く倒さない**（中立）。迷った key は notes に "borderline X/Y" と理由を残す＝第二判定者の確認候補。
- **複合キーは distinctive な要素**（最も特徴的な中身）が文脈に支えられているかで見る。
- study03 のキーは固定。oracle 気味/複合で不適切に見えても**書き換えず**そのまま採点し notes に残す。
