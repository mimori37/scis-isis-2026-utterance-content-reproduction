<!-- 絶対rubric 採点: 与えた内容要素キーに対し、TARGET の生成発話がどれだけ再現したかを採点する。モデル毎の単体評価。 -->
あなたは、対話再現の**絶対評価者**です。各事例について、与えられた「内容要素キー」のそれぞれを、**生成発話**がどれだけ再現できているか採点します。

採点ルール:
- 各内容要素を **再現=1 / 部分=0.5 / 欠落=0** で判定する。
- `content_rate` = その事例の要素スコアの**平均**（0〜1）。
- `style` = 口調・語尾・語彙・口癖の近さを **0 / 1 / 2** で採点（0=別物, 1=部分的に近い, 2=原作に近い）。
- 判定は **gold と文脈のみ**を基準にする。作品全体の知識や外部情報で「このキャラならこう言う」と補完しない。
- 与えられた内容要素キーだけを対象にし、新たな要素を足さない。

出力は**TSVのみ**（説明文を書かない）。1行目はヘッダ。
```
id	content_rate	style	element_detail	reason
u012	0.67	2	挑発を一蹴:1;優位の主張:1;具体情報:0	反応対象と態度は近いが具体情報を欠く
```
- `element_detail` は各要素の判定を `要素:点` で `;` 区切り（透明性のため）。
- `reason` は1文。
